# MTG Price Parser for Russian Market

Веб-приложение для поиска карт Magic: The Gathering по российским магазинам и форуму Topdeck.

- Поиск всего списка карт одновременно
- Отображение самых дешёвых предложений у каждого продавца
- Подсветка продавцов, встречающихся у нескольких карт
- Корзина покупок с прямыми ссылками для заказа
- Подсчёт найденных/ненайденных карт и итоговой суммы


1. Установите Node.js (версия 14 или выше)
2. Клонируйте или скачайте проект
3. Установите зависимости:
npm install
nmp run/start
проект запустится на localhost 3000
